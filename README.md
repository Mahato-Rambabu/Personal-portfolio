# Personal Portfolio — Rambabu Mahato

My personal developer portfolio showcasing my projects, skills, and experience as a Full Stack Developer.

🔗 **[Live Site](https://personal-portfolio-ten-psi-52.vercel.app/)**

---

## 🛠 Built With

- Next.js
- Tailwind CSS
- Responsive design — works on all screen sizes

---

## 📌 Sections

- **Hero** — introduction and CTA
- **About** — background and skills overview
- **Projects** — QRAR, FitPlay, TalkMore, and more
- **Skills** — tech stack breakdown
- **Contact** — reach out form

---

## 🚀 Run Locally

```bash
git clone https://github.com/Mahato-Rambabu/Personal-portfolio.git
cd Personal-portfolio

# Open index.html directly in your browser
# or use Live Server in VS Code
```
